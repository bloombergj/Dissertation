# Dissertation
Code referenced in my PhD thesis

This includes code for chapters 1 and 2. 
For each chapter, there are separate files for 
1) dada2 pipeline
2) decontam identifying contaminant taxa
3) phyloseq analyses which take the products of dada2, combine them into a phyloseq object, filters the taxa with the decontam products, and conducts further filtering, plotting, and statistical testing described in my thesis.
